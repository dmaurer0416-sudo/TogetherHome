# 🏠 TogetherHome

TogetherHome is a roommate collaboration platform designed to simplify shared living. It provides one place for roommates to manage finances, organize chores, coordinate schedules, and communicate, helping reduce misunderstandings and keep everyone accountable.

---

## Features

- 💰 Split rent and utility bills
- 📅 Shared household calendar
- 🧹 Chore assignments and tracking
- 🛒 Shared grocery & shopping lists
- 💬 Group messaging
- 📄 Store important household documents
- 🔔 Bill and chore reminders
- 📊 Household expense dashboard
